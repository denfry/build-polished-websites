# Example prompts

## New landing page

```text
Use $build-polished-websites to build this landing page from the supplied brief
and brand assets. Establish a visual thesis first, preserve the current stack,
then verify the production build at mobile, tablet, desktop, and one awkward
width. Run the Lighthouse quality gate and report evidence.
```

## Any new site from a short brief

```text
Use $build-polished-websites to build a site for <business, place, event, or
person>. Gather the real facts first, choose the archetype, mine the subject's
world for a source, compare three candidate directions, and show me the
direction card before building. Review screenshots at all widths until every
design-review dimension scores at least 4, then run slop-scan and Lighthouse.
```

## Make an existing site beautiful

```text
Use $build-polished-websites to capture this site with snap.mjs, score it with
the design-review rubric, and run slop-scan. Propose a direction card that fixes
the weakest dimensions without changing the framework, then implement it and
show before and after screenshots.
```

## Remove AI slop

```text
Use $build-polished-websites to review this frontend for generic AI design
patterns. Keep what is product-specific, replace unsupported claims and
decorative defaults, and produce a more distinctive visual system. Do not
change the framework.
```

## WordPress and WooCommerce

```text
Use $build-polished-websites to redesign this WooCommerce product template.
Keep the parent theme updateable, preserve editor ownership and the SEO plugin,
prefer hooks over template copies, and test simple, variable, unavailable, and
sale products on staging.
```

## 1C-Bitrix

```text
Use $build-polished-websites to integrate this design into 1C-Bitrix. Keep all
custom code under /local, separate component logic from templates, design cache
identity and invalidation, and verify anonymous and authenticated permission
variants.
```

## Tilda

```text
Use $build-polished-websites to improve this Tilda project without turning
every section into Zero Block. Preserve marketing's editing workflow, review
custom code and forms, and test the published page rather than only the editor
preview.
```

## Tilda export integration

```text
Use $build-polished-websites to review our Tilda API export pipeline. Treat
Tilda as the editorial source, remove manual patches to generated HTML, protect
the API secret, make publishing idempotent and reversible, and verify the final
host application's caches and browser output.
```

## Shopify

```text
Use $build-polished-websites to rebuild this Shopify product experience using
JSON templates and merchant-editable sections. Work in a development theme,
preserve app blocks and commerce behavior, run Theme Check, and audit home,
product, and collection templates.
```

## Audit only

```text
Use $build-polished-websites to audit this site without editing it. Report
visual-direction problems, platform-contract risks, accessibility failures,
security and SEO issues, and a prioritized verification plan. Distinguish
observed evidence from assumptions.
```
